Encontre as fraquezas antes que outros encontrem.

Qypher é um aplicativo desktop que varre sites autorizados e código local em busca de arquivos expostos, falhas de configuração e credenciais vazadas — e explica, em linguagem clara, como corrigir.

// RECURSOS

O que o Qypher encontra

Verificações reais sobre a resposta do alvo — sem força bruta, sem exploração destrutiva e sem simular resultados.

[ exposição ]

Arquivos e segredos expostos

.env, .git, backups, dumps de banco, credenciais e painéis de debug acessíveis. Mostra uma prévia mascarada do que vazou, para você avisar o responsável.

[ http / tls ]

Configuração de transporte

HTTPS, validade e força do certificado, versões de TLS obsoletas, HSTS, e redirecionamento inseguro da porta 80.

[ cabeçalhos ]

Cabeçalhos de segurança

Força da CSP e do HSTS, clickjacking, cookies sem atributos seguros, CORS permissivo e divulgação de versões de software.

[ página ]

Conteúdo da página

Bibliotecas JavaScript vulneráveis, scripts de terceiros sem verificação de integridade, conteúdo misto, formulários sem proteção CSRF e source maps públicos.

[ ativo ]

Testes ativos não destrutivos

Reflexão de origem no CORS, métodos HTTP de escrita anunciados, TRACE e páginas de erro com rastro de pilha — sempre dentro do escopo autorizado.

[ código ]

Análise de código local

Triagem de padrões perigosos, possíveis segredos no repositório, infraestrutura como código (Docker/K8s/Terraform) e inventário de dependências com consulta OSV opcional.

// COMO FUNCIONA

Cole o link e analise

Duas intensidades: Quick Scan (configurações públicas) e varredura profunda (descoberta de arquivos expostos e testes ativos).

01 /

Autorize o alvo

Confirme que o site é seu ou que você tem permissão. O escopo fica preso à origem informada.

02 /

O motor varre

Requisições limitadas e controladas sobre o alvo, com DNS validado a cada salto. Nada do corpo é guardado em claro.

03 /

Leia e corrija

Cada achado traz evidência, impacto e correção. Gere um prompt pronto para colar no seu assistente de IA.

quick scan + cadeado varredura profunda + órbita modo terminal (REPL) prompt para IA exportar PDF / HTML / JSON histórico local
// SEGURANÇA E PRIVACIDADE

Feito para uso responsável

> princípios

✓

Local-first: a análise roda no seu computador. Sem conta, sem servidor obrigatório, sem telemetria.

✓

Somente com autorização: cada execução exige a confirmação de que você pode testar o alvo.

✓

Sem exploração destrutiva: apenas leitura e testes não destrutivos; nada de força bruta ou payloads de ataque.

✓

Segredos protegidos: o conteúdo exposto é exibido mascarado e redigido nas exportações; o valor inteiro nunca é guardado.
